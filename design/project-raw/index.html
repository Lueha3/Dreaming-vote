Track 05 · Trust02:36

제약이 곧 인증이다

"진짜 폰으로만 만들었나?"라는 의심이 사라져야 이 플랫폼이 삽니다. 그래서 검증을 숙제가 아니라 놀이로 설계했습니다.

Step 1 · Source

.band 파일 업로드

음원만이 아니라 프로젝트 파일 자체를 받습니다. 서버가 내부를 훑어 외부 플러그인·임포트 오디오를 잡아냅니다. 빼도 박도 못하는 물리적 증거 — 공개하면 다른 유저의 교과서가 됩니다.

자동 검사 · 학습 콘텐츠로 재활용
Step 2 · Proof

Proof of Work 영상

전체 트랙을 스크롤 재생하는 15~30초 화면 녹화가 있어야 정식 등록. 개러지밴드 특유의 화면이 그대로 담겨 "진짜 폰으로 뚱땅거렸네"라는 감성적 신뢰를 만듭니다.

틱톡 · 릴스 홍보 소재 이중 활용
Step 3 · Peers

피어 리뷰 — "잡았다 요놈"

개러지밴드 고수는 소리만 들어도 압니다. 가짜를 적발한 유저에게 포인트와 명예 배지. 고인물이 눈을 부라리며 지켜보는 커뮤니티 자정 장치입니다.

적발 보상 · 고수 리텐션 장치
+1 · Audit (Phase 3)

사운드 핑거프린팅

개러지밴드 기본 루프·악기 파형 DB를 구축, 외부 고퀄 샘플 비중이 높은 곡을 자동으로 검토 대상에 올립니다. 수익이 생기면 투자할 기술 부채 항목.

RAW Verified → RAW Certified 배지
Track 06 · Business03:04

불완전함이 곧 상품이다

공유 플랫폼은 트래픽이 터져도 돈이 안 되기 쉽습니다. 그래서 처음부터 세 개의 파이프를 설계합니다.

Option A

챌린지 & 컴필레이션

매달 제약 챌린지("808 Bass + Grand Piano만") → 선정곡을 앨범으로 묶어 실제 음원 유통 & 수익 배분. 방구석에서 멜론까지.

Phase 2 · 커뮤니티 엔진 겸용
Option B

.band 프로젝트 마켓

"이 곡 어떻게 만들었어?" — 프로젝트 파일과 모바일 작곡 노하우를 유료 판매. 검증 시스템이 이미 만들어 둔 자산이 그대로 상품이 됩니다.

Phase 3 · 수수료 15~20%
Option C

브랜드 협업 — Apple이 사랑할 그림

"아이폰만으로 창작하는 생태계." 규모가 커지면 기기 협찬 · 브랜드 챌린지 스폰서십으로 확장할 수 있는, 애플이 환장할 서사입니다.

장기 · 비제휴 팬 플랫폼으로 시작
Track 07 · Universe03:26

BlueHumanity 세계관의
자아실현 파트

AI가 모든 걸 대신해 주는 시대, 인간이 직접 무언가를 만드는 행위 자체가 가치가 됩니다. RAW는 그 질문에 대한 우리의 두 번째 대답입니다.

PHASE 1

"부모가 먼저 바로 서야, 아이가 AI 시대의 주인이 된다." — 지금 만들고 있는 본진.

PHASE 2

CREATOR Project RAW · 지금 이 기획

"AI의 완벽함 대신, 인간의 불완전한 진정성을 노래하라." 부모와 아이가 아이폰 하나로 함께 곡을 만들어 올리는 순간, PARENTING과 CREATOR가 연결됩니다 — 아이의 창의적 자아실현이 기록으로 쌓이는 곳.

PHASE 3

ESSENCE 철학 · 인문학 살롱

"생산성을 넘어, 인간다움의 본질을 탐구하는 공동체." — 세계관의 종착지.
