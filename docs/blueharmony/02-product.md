# 02. 제품 기획 — 블루하모니 V2 "우리 아이의 10년 뒤"

## 1. 컨셉 재정의

| | 기존 프레임 (V1) | 재창조 프레임 (V2) |
|---|---|---|
| 정체성 | 부모교육 커리큘럼 앱 | **가족 관계 OS** — 순간을 구하고, 패턴을 바꾸고, 궤적을 보여준다 |
| 제공물 | 학습 과정(커리큘럼) | 상황 대사 스크립트 + 패턴 리포트 + 궤적 시뮬레이션 |
| 사용 시점 | 시간 날 때 공부 | **갈등이 터진 그 순간** + 자기 전 3분 |
| 예측의 대상 | 아이의 미래 모습 | 부모-자녀 **상호작용 패턴의 궤적** |
| 데이터 | 검사 1회 결과 | 매일 쌓이는 상호작용 로그 (종단 데이터) |

교육(공부하러 오는 앱)은 동기가 강한 소수만 남는다. 구조(急할 때 찾는 앱 + 매일 3분 습관)로
바꿔야 대중이 남는다. 커리큘럼은 사라지는 게 아니라, 코치와 리포트 안에 잘게 쪼개져 스며든다.

**포지셔닝 한 줄** — "오은영 박사님을 주머니에 넣고 다닐 순 없지만, 블루하모니는 넣고 다닐 수 있습니다.
그리고 블루하모니는 **우리 아이의 기질과 내 성향을 알고** 말합니다."

## 2. 타겟 사용자

### 주 타겟 (Beachhead)
**만 3~9세 자녀를 둔 30~40대 부모** 중, 훈육 갈등(떼쓰기·등원/등교 거부·형제 다툼·
미디어 전쟁·숙제 전쟁)을 주 3회 이상 겪고, 화낸 뒤 자책해 본 사람.
- 검색어로 정의하면: "아이한테 소리 지르고 후회", "훈육 어떻게", "기질 검사" 검색자.
- 이 구간을 고른 이유: ①언어적 갈등이 시작되고 ②부모의 개입 여지가 가장 크며
  ③위기감(초등 입학 전후)이 지불 의사로 이어지는 구간.

### 페르소나
| 페르소나 | 상황 | 블루하모니가 주는 것 |
|---|---|---|
| **지수(37, 워킹맘)** | 퇴근 후 방전 상태에서 7살 아들 떼쓰기 폭발. 육아서 3권 샀지만 2장 읽음 | 책 대신 SOS 코치. 상황 프리셋 2탭 → 지금 할 말 |
| **민재(41, 아빠)** | 본인이 엄한 아버지 밑에서 자람. "나는 안 그러려 했는데" 순간 폭발 후 자괴감 | 미래 거울 — 내 패턴의 궤적을 눈으로 확인, 대물림 끊기 서사 |
| **은영(34, 예비 부모/영아 부모)** | 갈등은 아직 없지만 불안. 기질 검사·검사류 콘텐츠 애호 | 기질 나침반 + 조합 카드(공유 바이럴 진입점) |

2차 사용자: 조부모(황혼육아), 교사·상담사(→ Phase 2 B2B 좌석), 부부 파트너(초대 시트).

## 3. 세 개의 엔진 + 하나의 광장

### 엔진 A — 순간 코치 (SOS Coach) · *"지금 당장 뭐라고 하지?"*
급한 순간의 첫 화면. 목표 응답 시간: **입력 시작부터 첫 대사까지 10초 이내.**

- **입력 3형태**
  1. 상황 프리셋 원탭 — 런칭 시 12개: 떼쓰기/드러눕기, 등원·등교 거부, 형제·남매 다툼,
     미디어(유튜브·게임) 종료 전쟁, 밥 안 먹기, 숙제·학습 거부, 거짓말, 물건 던지기·때리기,
     공공장소 소란, 아침 준비 전쟁, 잠자리 거부, "싫어! 미워!" 말대답
  2. 자유 채팅(텍스트)
  3. 음성 입력(한 손으로 아이 잡고 있는 상황 대응)
- **출력 포맷 (고정 3단)**
  1. **지금 이 말** — 그대로 읽어도 되는 대사 2~3개 (아이 기질 × 부모 성향 × 아이 나이 반영)
  2. **지금은 금지** — 이 조합에서 특히 역효과인 말 1~2개 + 한 줄 이유
  3. **30초 원리** — 왜 이 대사인가 (근거 이론 태그: 감정코칭/행동주의/애착 등)
- **사후 루프**: 상황 종료 후 "어떻게 됐어요?" 원탭 피드백(먹혔다/안 먹혔다/못 써봤다)
  → 개인화 학습 + 전체 스크립트 승률 데이터로 축적. **이 피드백 데이터가 회사의 해자다.**

### 엔진 B — 기질 나침반 (Compass) · *"우리 조합은 왜 부딪히는가"*
온보딩이자 바이럴 진입점.

- **부모 양육 성향 검사** (약 5분) — 훈육 스타일(권위형/허용형/방임형/민주형 축),
  감정 반응 패턴, 본인의 피양육 경험(대물림 축) 문항 포함
- **아이 기질 검사** (부모 관찰 응답, 약 5분) — 자극 민감도, 활동성, 적응성,
  반응 강도, 지속성 등 기질 심리학 표준 차원 기반 (상세: 03-ai-engine.md §2)
- **가족 조합 카드** — "화산형 부모 × 유리병 기질 아이" 식의 조합 아키타입 +
  우리 집 3대 충돌 예상 지점 + 조합 강점 1개(No-Blame: 강점을 반드시 포함)
  → 이미지 카드로 저장·공유 (기존 성향 카드 + ShareEvent 인프라 재활용)
- **충돌 지도** — 조합 카드의 상세판. 상황 프리셋 12개 각각에 대해 우리 조합의
  위험도·핵심 지침을 매핑해 둔 상시 참조 화면
- 배우자 초대: 부모 2인의 성향이 다를 때 "부부 훈육 온도차" 리포트 (초대 = 성장 루프)

### 엔진 C — 미래 거울 (Future Mirror) · *"우리 아이의 10년 뒤"*
V2의 간판 컨셉. 단, 원칙 2(거울이지 점쟁이가 아니다)에 따라 설계한다.

- **데일리 3분 기록** — 저녁 푸시 → ①오늘의 순간 1개 태깅(충돌/좋았던 순간, 상황 프리셋에서 선택)
  ②그때 내가 한 말 한 줄 ③감정 온도 슬라이더. 30초~3분 컷.
- **자존감 저금통** — 기록이 쌓일 때마다 입금/출금으로 시각화되는 홈 위젯.
  격려·공감 발화는 입금, 비난·비교 발화는 출금. 게이미피케이션이자 궤적의 원료.
  (출금이 많아도 잔고를 '망함'으로 표시하지 않는다 — "이번 주 입금 기회 3번" 식 전환 프레임)
- **주간 거울 리포트** — 이번 주 패턴 요약: 반복된 충돌 상황 Top3, 나의 대응 유형 분포,
  코치 스크립트 사용 후 결과, 다음 주 미션 1개.
- **궤적 시뮬레이션 ("10년 뒤")** — 4주 이상 데이터가 쌓이면 열리는 프리미엄 기능.
  현재 패턴이 지속될 때의 관계 궤적 A와, 미션을 수행했을 때의 궤적 B를 **나란히** 보여준다.
  아이 개인의 미래 단정이 아니라 "이 패턴이 계속되면"의 조건부 서사임을 UI에 명시.
- **내면 목소리 (월 1회)** — 이번 달 기록을 바탕으로 "아이의 시점에서 본 이번 달"을
  짧은 편지로 재구성. 블루하모니에서 감정적으로 가장 강력한 기능이므로 가장 절제해서 쓴다:
  월 1회 한정, 열람 전 안내("시뮬레이션입니다"), 반드시 희망적 행동 제안으로 마무리.

### 네 번째 기둥 — 광장 (조합 기반 육아 커뮤니티) · *"훈수 대신 공감"*
알고리즘(코치)이 정답을 주고, 광장이 정서를 준다. 혼자 견디는 육아가 이탈의 근본 원인이므로
커뮤니티는 부가 기능이 아니라 리텐션 인프라다. **블루휴머니티 광장의 검증된 패턴을 그대로
벤치마킹**해 만든다 — 코드가 이미 이 리포에 있어 MVP 비용이 낮다.

| 블루휴머니티 광장 (원본 패턴) | 블루하모니 광장 (번역) |
|---|---|
| 카테고리 칩: 일상 / 기도해주세요 / 동아리광고 | **순간** / **고민 나눠요** / **먹힌 말** |
| "기도했어요·공감" — 글당 1인 1회 단일 반응 | **"함께해요"**(고민) / **"공감"**(일반) — 동일 규칙 |
| 익명 옵션 (민감한 기도제목 보호) | 익명 기본 제안 (훈육 고민은 민감) — 단 **조합 배지는 유지**: "화산형×유리병 · 익명" |
| "응답됐어요" 마킹 + 간증 한 줄 | **"한숨 돌렸어요"** 마킹 + 후기 한 줄 — 해결 서사가 피드에 쌓임 |
| 이번 주 아이스브레이커 질문 고정 카드 + 답변 태깅 | **이번 주 질문** 육아판 ("오늘 아이에게 가장 많이 한 말은?") |
| 시스템 카드 (새가족 환영·생일) | 시스템 카드 (첫 검사 완료 환영, 저금통 마일스톤 축하) |
| 탭 새소식 배지 (카카오톡 스타일) + 사진 더블탭 공감 | 동일 유지 |
| 신고 → 운영 검토 큐 (ContentReport) | 동일 + **위기 신호 자동 감지 승격** (03-ai-engine §6) |

블루하모니만 가능한 차별점:
- **익명 + 조합 배지 공존** — 익명이어도 "같은 조합" 컨텍스트가 붙어 조언이 맞춤형이 된다.
  맘카페 익명글의 공감 품질 편차 문제를 구조로 해결.
- **"우리 조합만" 필터** — 화산×유리병 부모끼리 모이는 피드. 기질 데이터 없는 커뮤니티는 흉내낼 수 없다.
- **먹힌 말 코너** — SOS 코치에서 "먹혔다" 피드백을 남기면 그 대사를 바로 광장에 공유 제안.
  제품(코치)과 커뮤니티가 서로를 성장시키는 순환이자, 스크립트 승률 데이터의 사회적 증명.
- **광장의 약속** (No-Blame의 커뮤니티 적용) — "훈수와 비난은 사양해요. 정답은 코치가,
  공감은 이웃이." 고정 카드 + 모더레이션 기준으로 명문화.

## 4. 코어 루프

```
[급할 때 · 수시]                       [매일 · 3분]                        [매주 · 5분]
 갈등 발생                              저녁 푸시                            일요일 저녁
   │                                     │                                   │
   ▼                                     ▼                                   ▼
 SOS 코치 → 대사 사용 ──────────▶ 오늘의 순간 기록 ──────────▶ 주간 거울 리포트
   │            │                        │                                   │
   │            └── 결과 피드백 ─────────┤ (자존감 저금통 입출금)             ├─ 다음 주 미션 1개
   │                                     │                                   │
   └────────────────────────────────────┴───────────── 데이터 축적 ──────────┴──▶ 궤적 시뮬레이션
                                                                                  (4주+, 프리미엄)
```

- **획득 루프**: 기질 검사 → 조합 카드 SNS 공유 → 신규 유입 (K-factor 측정: ShareEvent 재활용)
- **습관 루프**: 저녁 푸시 → 3분 기록 → 저금통 애니메이션 → 스트릭
- **커뮤니티 루프**: 고민 글 → 같은 조합 부모의 함께해요·댓글 → 홈 '광장 소식' 카드로 재방문 →
  코치 사용("먹힌 말" 공유) → 다시 광장. 탭 배지·푸시가 이 순환을 돌린다.
- **결제 루프**: 무료로 검사+제한 코치+광장 → 코치 무제한·주간 리포트·궤적 시뮬레이션·배우자 시트는 구독
  (광장은 전 구간 무료 — 커뮤니티는 과금 장벽 뒤에 두지 않는다)

## 5. 화면 구조 (IA)

하단 탭 5개 (기존 BottomTabBar 셸 + 새소식 배지 재활용). 광장이 코어에 들어오면서
'우리 가족'은 마이 탭으로 통합하고, 급할 때 쓰는 코치는 **중앙 SOS 원형 버튼**으로 승격:

| 탭 | 이름 | 내용 |
|---|---|---|
| 1 | **오늘** (홈) | 오늘의 미션, 3분 기록 CTA, 자존감 저금통 위젯, 스트릭, **광장 소식 카드** |
| 2 | **광장** | 이번 주 질문, 카테고리 피드(순간/고민 나눠요/먹힌 말), "우리 조합만" 필터, 새소식 배지 |
| 3 | **코치** (중앙 SOS) | 상황 프리셋 그리드 + 채팅/음성. 중앙 원형 버튼 — 급할 때의 근육기억 자리 |
| 4 | **거울** | 주간 리포트 아카이브, 궤적 시뮬레이션, 내면 목소리 |
| 5 | **마이** | **우리 가족**(성향·기질 프로필, 조합 카드, 충돌 지도, 배우자 초대, 다자녀), 광장 닉네임, 구독, 알림, 데이터 관리, 위기 지원 연락처 상시 노출 |

온보딩 플로우: 가입(소셜) → 아이 등록(출생연도·호칭) → 부모 검사 → 아이 기질 검사
→ 조합 카드 발급(공유 유도) → 첫 SOS 시연(샘플 상황) → 저녁 알림 허용. 목표 12분 내 완주.

## 6. MVP 범위 (V2 런칭 컷)

| 포함 (8주 빌드) | 제외 (V2.5+) | 제외 이유 |
|---|---|---|
| 검사 2종 + 조합 카드 + 공유 | 아이 다인 비교 리포트 | 다자녀는 등록만 받고 리포트는 후속 |
| SOS 코치 (프리셋 12 + 채팅) | 음성 입력 | STT 품질 검증 후 |
| 데일리 3분 기록 + 저금통 | 자동 일기(사진·캘린더 연동) | 프라이버시 설계 선행 필요 |

## 8. 성장 장치 (제품 내장)

1. **조합 카드 공유** — 결과 카드에 "우리 집 조합 확인하기" 딥링크. 검사류 콘텐츠는
   한국 SNS에서 검증된 바이럴 포맷 (MBTI 학습 효과).
2. **배우자 초대** — "이 리포트, 남편/아내도 봐야 하지 않아요?" 초대 시 양쪽 모두
   프리미엄 1주 체험. 초대받은 배우자는 CAC 0원 유저.
3. **'이 말 대신 이 말' 카드** — 주간 리포트의 베스트 대사를 익명 카드로 공유 가능.
   콘텐츠 마케팅(쇼츠 시리즈)과 동일 포맷으로 제품-마케팅 일관성.
4. **스트릭·저금통** — 잔고와 연속 기록이 손실 회피를 자극 (듀오링고 문법).
5. **광장** — 고민글의 함께해요·댓글이 홈 소식 카드와 탭 배지로 돌아와 재방문을 만들고,
   '먹힌 말' 공유가 코치의 사회적 증명이 된다. 혼자가 아니라는 감각 = 구독 유지의 정서적 바닥.
