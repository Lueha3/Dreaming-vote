# 04. 사업 로드맵 — 생존 증명에서 정서 OS까지

기준일: 2026-07. 보유 자산: V1 출시 경험(포트원 결제 연동·통신판매업 신고 완료),
본 리포의 재활용 가능한 코드베이스, 모두의창업 지원(멘토 기관: 스파크랩).

## 1. 전체 그림

```
2026 Q3          2026 Q4 ~ 2027 Q1     2027                  2028+
Phase 0          Phase 1               Phase 2               Phase 3
재창조 ────────▶ 검증 ───────────────▶ 확장 ───────────────▶ 플랫폼
V2 빌드(8주)     런칭·유료화·리텐션     B2B2C/B2G·예측엔진v1   PARAN AI SDK·글로벌
"만든다"         "돈 내는 이유를 증명"  "채널을 복제"          "표준이 된다"
                                                             (블록체인 재검토는 이후)
```

각 페이즈는 **통과 조건(Gate)** 을 만족해야 다음으로 간다. 조건 미달 시 다음 페이즈
착수가 아니라 현 페이즈 피벗이 정답이다.

## 2. Phase 0 — 재창조 (2026.7 ~ 2026.9, 8주)

| 주차 | 마일스톤 |
|---|---|
| 1~2주 | 검사 문항·조합 아키타입 설계, 스크립트 라이브러리 초안(프리셋 12 × 주요 조합), 브랜드 리네이밍(리포 정리) |
| 3~5주 | 검사→조합 카드 플로우, SOS 코치(캐시+LLM 스트리밍), 데일리 기록+저금통 |
| 6~7주 | 주간 거울 리포트, 위기 프로토콜, 결제 재연동, 온보딩 튜닝(12분 컷) |
| 8주 | 비공개 베타 30~50가정 (맘카페·지인·V1 유저 재소환) → 관찰: 검사 완주율, SOS 실사용 여부 |

**Gate → Phase 1**: 베타에서 ①온보딩 완주율 60%+ ②베타 가정의 50%+가 첫 주 SOS 코치
실전 사용 ③"이 말 그대로 써봤다" 정성 피드백 확보.

## 3. Phase 1 — 검증 (2026.10 ~ 2027.3)

- **정식 런칭**: "우리 아이의 10년 뒤" 컨셉 캠페인. 조합 카드 바이럴 + 쇼츠 시리즈(§7).
- **유료화 가동**: 프리미엄 구독 오픈 (§6). 런칭 얼리버드 연간권.
- **V2.5 업데이트**: 궤적 시뮬레이션 정식 공개(4주 데이터 보유 유저 대상 — 자연스러운
  리텐션 장치이자 업셀 순간), 내면 목소리(자문단 감수 후).
- **자문단 1호 영입** (§8) + 검사 문항 타당화 공동 프로젝트 킥오프.
- **정부지원 트랙**: 초기창업패키지·청년창업사관학교 등 시기 맞는 사업 1~2개 +
  모두의창업/스파크랩 멘토링을 자문단·투자 네트워크로 연결.

**Gate → Phase 2**: ①MAU 5,000+ ②유료 전환 3%+ ③M1 리텐션 30%+ ④주간 기록 습관
(WAU 중 주 3회+ 기록 비율 25%+) ⑤위기 프로토콜 무사고 운영.
(수치는 목표치 — 미달 항목이 있으면 그 항목을 고치는 것이 Phase 2 착수보다 우선.)

## 4. Phase 2 — 확장 (2027)

- **B2B2C/B2G 채널화**: 어린이집·유치원 부모교육(원 단위 좌석 라이선스),
  지자체·육아종합지원센터 부모교육 프로그램 납품, 기업 복지몰(가족 복지 카테고리).
  한국은 저출생 대응 예산과 부모교육 수요가 공공에 몰려 있어 B2G가 현실적 확장 경로다.
- **예측 엔진 v1**: 코호트 기반 개입 효과 통계("비슷한 조합 n가정에서 효과") 상용화
  → 궤적 시뮬레이션의 ② 연구 층을 자사 데이터로 대체 시작. (03-ai-engine §4)
- **검사 타당화 완료**: "OO 교수팀과 공동 타당화한 검사"로 리브랜딩 — 보도자료·B2G 신뢰 자산.
- **투자**: 시드 라운드(TIPS 연계 포함) — 근거: B2C 유료 전환 증명 + B2B 파이프라인 +
  데이터 자산 D1~D2. 스파크랩 네트워크를 1순위 활용.
- **팀 빌딩**: 창업자(개발) + 아동심리 전문 인력(정규/파트) + 콘텐츠 마케터 — 3~5인.

**Gate → Phase 3**: ①B2B/B2G 유료 계약 3건+ ②구독 매출로 고정비 커버(램프 가능한 손익) ③D2 데이터 확보.

## 5. Phase 3 — 플랫폼 (2028+)

- **PARAN AI 모듈화**: 조합 프로파일링 + 개입 정책 엔진을 API/SDK로 분리,
  키즈 디바이스·홈로봇·에듀테크·상담 플랫폼에 임베드. "정서적 뇌"의 v0.
- **글로벌 파일럿**: 육아 문화가 근접한 일본·대만부터 (검사·스크립트 로컬라이즈).
- **연구 자산화**: 종단 데이터(D3) 기반 공동 연구·논문 — "유년기 상호작용 ↔ 이후 발달"
  이라는 창업 원점 질문에 자사 데이터로 답하기 시작하는 단계.

## 7. GTM — 콘텐츠가 곧 제품 데모

1. **쇼츠 시리즈 "이 말 대신 이 말"** — 상황(떼쓰기) → 흔한 말(역효과) → 블루하모니 대사.
   제품의 SOS 출력 포맷 그대로가 15초 콘텐츠가 된다. 제작비 최소, 제품 일관성 최대.
2. **창업자 서사** — "부모에게 이해받지 못한 아이가 만든, 부모를 위한 앱"
   (01-vision §3의 분리 원칙 준수: 서사는 브랜드 채널에서, 제품은 No-Blame으로).
   대물림을 끊으려는 3040 부모 — 특히 아빠 세그먼트 — 에 강하게 공명하는 포지션.
3. **조합 카드 바이럴** — 검사류 공유 문법. 맘카페·인스타 육아 계정 시딩.
4. **전문가 협업 콘텐츠** — 자문단 감수 과정 자체를 콘텐츠로 (신뢰 구축 + 영입 레버리지).
5. **커뮤니티 시딩** — 초기엔 자체 커뮤니티를 만들지 않는다(운영 비용). 기존 맘카페·
  당근 동네생활에 기생 성장, Phase 2에서 Club 코드로 소모임 부활 검토.

## 8. 전문가(자문단) 영입 전략 — 지원서 질문 ①에 대한 실행안

"저명한 전문가를 어떻게 아군으로 만드나"의 답은 **거래 설계**다. 명분만으로는 움직이지 않는다.

| 단계 | 대상 | 우리가 주는 것 (Give) | 받는 것 (Get) |
|---|---|---|---|
| 1. 감수 (Phase 1) | 아동심리 박사급 1~2인 (신진·실무형이 현실적) | 자문료 + 앱 내 실명 크레딧 + 미디어 노출 | 스크립트·검사 감수, 위기 프로토콜 검증 |
| 2. 공동설계 (Phase 1~2) | 대학 연구실 (산학협력) | 비식별 데이터 접근 + 공동연구비 + 논문 IP | 검사 타당화, 알고리즘 근거 강화 |
| 3. 간판 (Phase 2) | 저명 전문가·학회 | 자문 지분(0.x%대) + '공동 개발' 브랜딩 | 신뢰 간판, B2G 문 열기 |

- 접근 순서는 반드시 1→3. 무명 상태에서 간판급에 직진하면 거절 확률만 높인다.
  1단계 감수 이력과 실사용 데이터("월 n만 건의 실제 훈육 상황 데이터")가 3단계의 미끼다.
- 경로: 스파크랩 멘토망 → 대학 산학협력단 → 학회 포스터/발표 → 저서 있는 전문가 순.
- 핵심 피치: "선생님의 이론을 논문 밖 n만 가정의 일상에 적용하고, 그 효과 데이터를
  돌려드립니다." — 전문가에게 우리는 앱이 아니라 **현장 실험 인프라**다.

## 9. 재무·투자 전략 — 지원서 질문 ②에 대한 실행안

- **부트스트랩 구간 (Phase 0~1)**: 1인 개발 + AI 툴체인으로 인건비 최소화(이미 증명된
  방식). 정부지원금으로 마케팅·자문료 충당. 목표: 월 고정비를 구독 매출로 덮는 시점을
  Phase 2 초로.
- **시드 (Phase 2)**: 유료 전환·리텐션 지표 + B2G 파이프라인을 들고 TIPS 트랙.
  내러티브는 "육아 앱"이 아니라 **"가족 상호작용 데이터 플랫폼의 B2C 진입로"** 로.
  (앱은 경쟁 많고 멀티플 낮다. 데이터 자산 D1~D2와 PARAN AI 로드맵이 밸류에이션 축.)
- **하지 말 것**: 매출 없는 상태에서의 대형 마케팅, 검증 전 다각화(파생 프로젝트 3~4개
  동시 전개는 지원서의 계획이었으나 — 1인 팀에서는 코어 루프 하나를 이기는 것이 먼저다.
  파생은 Phase 2 이후 '채널'로 푼다: 같은 엔진, 다른 세그먼트 앱).

## 10. KPI 체계 (노스스타 + 가드레일)

- **노스스타**: 주간 '구조된 순간' 수 — SOS 사용 후 "먹혔다" 피드백 건수.
  (사용량이 아니라 결과를 세는 지표. 이 숫자가 곧 미션 달성량이다.)
- 획득: 검사 완주율, 조합 카드 공유율, K-factor, CAC
- 습관: D7/D30 리텐션, 주 3회+ 기록 유저 비율, 저녁 푸시 → 기록 전환율
- 수익: 무료→유료 전환율, MRR, 이탈률, LTV/CAC
- 품질·안전: 스크립트 승률(먹힘 비율), ParsingLog 실패율, 위기 프로토콜 대응 SLA
- 대시보드: 기존 MetricSnapshot + admin/stats 확장 (Phase 0에 포함)

## 11. 경쟁 구도와 해자

| 대안재 | 강점 | 블루하모니의 차별 |
|---|---|---|
| 육아서·오은영 콘텐츠 | 신뢰·대중성 | 일반론이다. 우리는 **우리 집 조합**에 맞는 말을 **그 순간에** 준다 |
| 기질검사·상담 플랫폼(그로잉맘 등) | 전문성, 검증된 검사 | 검사는 1회성 이벤트. 우리는 검사 이후의 **매일**을 잡는다 |
| 놀이·콘텐츠 앱(차이의 발견 등) | 콘텐츠 볼륨 | 콘텐츠 소비가 아니라 **갈등 순간의 개입**이 코어 |
| 범용 챗봇(ChatGPT 등) | 무료·범용 | 아이 기질×부모 성향×이력 컨텍스트, 3단 출력 포맷, 승률 데이터, 위기 프로토콜 — 범용 챗봇이 못 쌓는 것 |
| 맘카페 집단지성 | 공감·실전성 | 익명 조언의 품질 편차 없음, 죄책감 자극 없음 |

**해자의 순서**: ①스크립트 승률 데이터(개입→결과 피드백 루프) → ②조합별 종단 데이터
→ ③전문가 타당화 간판 → ④B2G 레퍼런스. 전부 시간이 쌓아주는 자산이라 후발이 돈으로 못 산다.
