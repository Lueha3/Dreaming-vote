# 05. 시뮬레이션 트랙 — "미래 거울을 플레이하다"

> **방향 전환 (2026-07)**: 창업자 결정으로 S-트랙은 **물리 엔진 기반 실사형(UE5, Steam 타깃)**
> 으로 확정 — 상세 설계는 [06-physics-sim.md](./06-physics-sim.md). 이 문서의 아이 브레인,
> 퀘스트·보상 구조, No-Blame 게임 문법, 연령 밴드는 그대로 유효하며 06의 기반이 된다.
> §3.1~3.2의 웹 3D(r3f) 단계는 UE5 그레이박스(06 §5 P1)로 대체된다.

> 질문: 모바일에서 게임처럼 돌아가는 실제형 3D 육아 시뮬레이션이 가능한가?
> 답: **가능하다. 단, '실사형'이 아니라 '실제 우리 아이형'으로 만들어야 이긴다.**

## 0. 결론 요약 (전략 판단 3개)

1. **그래픽은 실사(포토리얼)가 아니라 스타일라이즈드 3D로 간다.**
   - 실사 아동 모델은 불쾌한 골짜기를 넘기가 극도로 어렵고(대형 스튜디오도 실패하는 영역),
     제작비가 1인 팀 규모를 벗어난다.
   - 더 중요한 윤리 문제: 가상 아이가 진짜 아이처럼 보일수록, 시뮬 안의 실패 경험이
     현실 관계로 전이될 위험이 커진다. 연습은 "우리 아이 같지만 우리 아이는 아닌" 안전거리가 필요하다.
   - 학습 효과도 스타일라이즈드가 낫다 — 적당한 추상화가 투사(이 아이 = 내 아이)를 쉽게 만든다
     (만화 캐릭터에 자신을 이입하는 원리). '실제형'의 본질은 그래픽 해상도가 아니라
     **행동의 사실성** — 우리 아이 기질 그대로 반응하는 것이다.
2. **시뮬의 차별점은 3D가 아니라 '아이 브레인'이다.** 우리는 이미 기질 벡터(나침반)와
   상황 분류(SOS 프리셋), 판정 원리(코칭 근거 태그)를 갖고 있다. 이 엔진에 몸(3D)을 입히는
   순서로 가야지, 3D부터 만들고 브레인을 끼우는 순서로 가면 망한다.
3. **V2 런칭을 지연시키지 않는 병행 트랙으로 간다.** 시뮬은 S0(브레인 검증) → S1(3D 수직 슬라이스)
   → S2(확장)의 게이트 구조로, 각 단계가 실패해도 본체(코치·광장·거울)는 무사하다.

## 1. 컨셉 — 육아의 비행 시뮬레이터

**포지셔닝 한 줄** — "조종사는 시뮬레이터에서 천 번 추락하고, 실제 하늘에선 추락하지 않는다.
블루하모니 플레이는 부모의 비행 시뮬레이터다. **실수는 여기서, 사랑은 현실에서.**"

- **본체 앱(SOS 코치)** = 실전: 갈등이 터진 순간의 컨닝페이퍼
- **시뮬(플레이)** = 훈련: 갈등이 터지기 전에 미리 겪고, 안전하게 실수하고, 회복을 연습하는 곳
- 둘은 같은 엔진(기질 × 상황 × 개입 원리)의 두 얼굴이다. 시뮬에서 연습한 상황은
  실전 SOS 승률이 올라간다 — 이 **전이(transfer) 지표**가 시뮬의 존재 증명이자 B2G 세일즈 근거가 된다.

**킬러 컨셉 — "우리 아이를 이식한다."**
일반 육아 게임(가상 아이 키우기)과의 결정적 차이: 플레이어의 실제 아이 **기질 프로필을
가상 아이에게 이식**한다. 자극 민감도 88%, 적응 느림, 지속성 높음인 이안이의 기질 그대로
반응하는 가상 아이 "이안(가명)"과 연습한다. 그리고 —

**"우리 아이의 사춘기를 미리 만나보세요."**
연령 슬라이더를 올리면 같은 기질의 아이가 4살 → 7살 → 11살 → 14살로 자란 모습과 만난다.
'우리 아이의 10년 뒤' 컨셉이 리포트(거울)를 넘어 **플레이 가능한 경험**이 된다.
이것이 시뮬 트랙의 간판 유료 콘텐츠다.

## 2. 게임 디자인

### 2.1 코어 루프 (1퀘스트 = 3~7분)

```
퀘스트 수령 ──▶ 상황 브리핑 ──▶ 대화 플레이 ──▶ 판정 ──▶ 디브리핑 ──▶ 보상
"저녁 7시,      아이 상태·맥락    선택지 or 자유발화   관계 게이지    아이의 내면    저금통 코인
 숙제 전쟁"     (비언어 신호!)     멀티턴 3~8턴       변화 요약     목소리 재생    +방 꾸미기
                                      │                              +스킬 노트    +앨범 카드
                                      ▼
                            실수하면? → 게임오버가 아니라 "회복 턴" 발동
                            (사과·재접속 대사로 만회 — 회복도 점수다)
```

- **판정은 정답 맞추기가 아니다.** 관계 게이지 3종 — 마음 온도(즉시 반응), 신뢰(누적),
  자존감 저금통(본체와 동일 메타포) — 가 오르내린다. 유일한 '실패'는 게이지가 아니라
  **회복 시도조차 안 한 채 끝내는 것**이다. (No-Blame의 게임 문법 번역)
- **디브리핑 = 아이의 내면 목소리.** 방금 장면을 아이 시점 한 단락으로 재생.
  "아빠가 소리를 낮췄을 때, 사실 나도 그만하고 싶었어." — 본체의 '내면 목소리' 기능을
  시뮬에서는 매 퀘스트 안전하게 쓸 수 있다(가상 아이니까). 시뮬이 본체보다 감정적으로 자유로운 이유.

### 2.2 아이 브레인 (시뮬레이션 모델)

```
입력: 기질 벡터(나침반 검사 6차원) × 발달 단계(연령 밴드) × 현재 상태
상태 게이지: 각성도(피곤·배고픔) · 감정(4분면) · 신뢰 잔고 · 오늘의 사건 플래그
    │
상태머신(결정적): 기질×상태 → 반응 모드 결정 (폭발/철회/협상/시험하기...)
    │                 ※ 유리병 기질은 위협에 '철회', 불꽃놀이 기질은 '폭발' — 기질별 분기
LLM(생성적): 반응 모드 + 연령별 언어 수준에 맞는 대사·행동 지시문 생성
    │                 ※ 프롬프트 콘솔(PromptVersion) 재사용 — 자문단 감수를 배포 없이 반영
판정기: 부모 발화 분류(감정코칭/지시/위협/회유/무시...) → 게이지 델타 + 근거 태그
```

- 상태머신이 뼈대(예측 가능·검증 가능·비용 0), LLM이 살(자연스러운 대사). LLM이 죽어도
  상태머신+사전 대사 뱅크로 플레이 가능(오프라인 폴백 — SOS 캐시 전략과 동일).
- 판정 루브릭은 코치의 개입 원리 태그 체계를 그대로 공유 — 시뮬과 실전이 같은 언어로 가르친다.

### 2.3 연령대 밴드 & 퀘스트 팩

| 밴드 | 발달 테마 | 대표 퀘스트 예 |
|---|---|---|
| 0~1 영아 | 수면·수유·울음 해석 | "새벽 3시, 이유 없는 울음" — 달래기 순서 연습 |
| 1~3 걸음마 | 자율성 폭발, 첫 "싫어" | "마트 바닥 드러눕기" — 공공장소 압박 속 대응 |
| 4~6 유아 | 감정 언어, 질문 폭발, 규칙 | "동생을 때렸다" — 행동 제지 + 감정 인정 동시에 |
| 7~9 초등 저 | 학습 습관, 또래 비교, 거짓말 | "숙제 전쟁" · "학원 가기 싫어" — 협상과 한계 설정 |
| 10~12 초등 고 | 사춘기 초입, 프라이버시, 미디어 | "방문을 잠갔다" — 존중과 개입의 선 긋기 |
| 13~16 청소년 | 대화 단절 위기, 정체성 | **"3일째 한마디도 안 한다" — 창업자 서사의 원점.** 단절을 되돌리는 재접속 연습 |

- 퀘스트 소재는 SOS 프리셋 12종과 광장의 실제 고민글(비식별 집계)에서 공급 —
  **커뮤니티가 시뮬의 콘텐츠 광산**이 된다. "이번 주 광장 Top 고민이 이번 주 퀘스트."
- 밴드별 8~12퀘스트 + 주간 신규 1개(운영). 우리 아이 현재 나이 밴드는 무료 일부 제공,
  다른 연령(특히 미래 밴드)은 프리미엄.

### 2.4 3D가 밥값을 하는 지점 — 비언어 신호

3D를 넣는 이유는 예쁜 그래픽이 아니라 **몸짓 읽기 훈련**이다. 실제 육아 기술의 절반은
말이 터지기 전의 신호를 읽는 것이다.

- 아이 아바타는 폭발 전 전조를 몸으로 보여준다: 어깨가 굳는다, 눈을 안 맞춘다,
  장난감을 꽉 쥔다, 목소리가 한 톤 올라간다. (blend shape 표정 + 애니메이션 상태 12~20종)
- 전조 단계에서 개입하면 보너스("신호를 읽었어요") — 폭발 후 수습보다 예방이 고득점.
  이것이 텍스트로는 가르칠 수 없고 3D여야만 가르칠 수 있는 것.
- 카메라는 부모 1인칭 시점 고정(방 안 시점) — 오픈월드가 아니다. 씬은 방 4종
  (거실·아이 방·마트·차 안)이면 퀘스트 대부분을 커버한다. **씬을 늘리지 말고 상황을 늘린다.**

### 2.5 보상 경제 (확정형 — 가챠 금지)

| 보상 | 내용 | 동기 설계 |
|---|---|---|
| 저금통 코인 | 퀘스트 완료·회복 성공 시 확정 지급 | 본체 자존감 저금통과 통합 — 연습도 입금이다 |
| 아이 방 꾸미기 | 코인으로 가구·벽지·장난감 (코스메틱 전용) | 수집·표현 욕구, 능력치 판매 금지 |
| 추억 앨범 | 잘 끝난 장면이 일러스트 카드로 저장 | "잘한 순간"의 물성화 — 광장 공유 가능(바이럴) |
| 스킬 노트 | 개입 원리 태그별 숙련도 (감정코칭 Lv.3 등) | 학습 진행의 가시화, 실전 SOS와 연동 표기 |
| 실앱 혜택 | 연속 플레이 시 SOS 무제한 쿠폰 등 | 시뮬 → 본체 순환 |

- **확률형 아이템 전면 금지.** 사행성 배제는 윤리이자 등급분류(전체이용가)·규제 리스크 관리다.
- 게임물 등급분류: 모바일은 앱마켓 자체등급분류로 처리 가능. 앱 내 게임 모드 형태로
  시작하면 절차가 가장 가볍다 — 별도 게임 앱 분리는 S2에서 판단.

## 3. 개발 계획

### 3.1 기술 스택 판단

| 선택지 | 장점 | 단점 | 판정 |
|---|---|---|---|
| **웹 3D (Three.js/react-three-fiber, 기존 Next.js PWA 내장)** | 코드베이스·인증·구독·AI 파이프라인 전부 재사용, 배포 즉시, 앱스토어 불필요(PWA), 스타일라이즈드 로우폴리는 중급 폰에서 충분히 60fps | 고급 애니 툴링 부족, 물리·파티클 한계 | **S1 채택** |
| Unity (C#) | 애니메이션·에셋 생태계 최강, 네이티브 성능 | 별도 코드베이스·언어, 빌드/스토어 파이프라인, 1인 팀 유지비 2배 | S2 전환 후보 (게이트 통과 시) |
| 2D/2.5D (카드·일러스트) | 최속·최저비용 | '게임처럼'의 기대치 미달 | **S0 프로토타입 전용** |

핵심 원칙: **씬 1개·아바타 1종·상황 다수.** 3D 야망이 아니라 시뮬레이션 깊이에 돈을 쓴다.

### 3.2 단계별 빌드 (게이트 구조)

> **플레이 가능한 체험판** — 이 문서의 S0 설계를 그대로 구현한 데모가
> [`s0-demo/blueharmony-play.html`](./s0-demo/blueharmony-play.html)에 있다 (브라우저에서 바로 실행).
> 같은 유리병 기질의 이안이를 4살(마트 드러눕기)·7살(미디어 종료)·14살(대화 단절)에서 만나는
> 퀘스트 3종: 전조 신호 보너스, 회복 턴, 관계 게이지, 내면 목소리 디브리핑, 확정형 코인 보상까지
> §2 게임 디자인 전체가 동작한다. 대사는 사전 검수된 대사 뱅크(상태머신) — 정식 S0에서 LLM 자유 발화가 얹힌다.
> 퀘스트 데이터는 [`s0-demo/quests.json`](./s0-demo/quests.json) (그래프 스키마 참고용).

**S0 — 브레인 검증 (2~3주, V2.5에 '연습 모드'로 탑재)**
- 3D 없이: 상황 카드 + 아이 상태 일러스트(표정 6종) + 멀티턴 대화 + 게이지 + 디브리핑.
- 아이 브레인(상태머신+LLM+판정기) 전체를 이 단계에서 완성 — 이게 진짜 개발이다.
- 퀘스트 10개(4~6세·7~9세 밴드), 본체 구독자 대상 베타.
- **Gate → S1**: 퀘스트 완료율 60%+, 재플레이율 30%+, "실전에서 써먹었다" 정성 피드백,
  전이 신호(연습 상황의 SOS '먹혔다'율 우위) 관찰.

**S1 — 3D 수직 슬라이스 (8~10주)**
- r3f로 거실 씬 1개 + 아이 아바타 1종(연령 모핑 3단계: 유아/초등/청소년 체형·얼굴 변형).
- 비언어 신호 시스템(표정 blend shape 10종 + 몸짓 애니 12종), 전조 읽기 보너스.
- 아트 파이프라인: AI 3D 생성(Meshy/Tripo류) 초안 → 외주 리터칭·리깅(캐릭터 1종 집중 투자)
  → Mixamo/수제 애니. **실제 아이 사진·얼굴 스캔은 금지** — 커스터마이즈는 머리·피부·옷
  프리셋까지만(§0-1 안전거리 원칙 + 아동 초상 데이터 회피).
- 음성 발화 입력(STT) 이 단계에서 도입 — "소리 내어 말하는 연습"이 몰입의 핵.
- **Gate → S2**: D7 재방문 시뮬 기여 확인, 세션당 2퀘스트+, 프리미엄 전환 기여(사춘기
  미리보기 유료 전환율), LLM 원가율이 구독가 안에서 수렴.

**S2 — 확장 (S1 게이트 통과 후)**
- 연령 밴드 6종 전체, 주간 퀘스트 운영 체계(광장 연동), 부부 협동 퀘스트(2인 플레이 —
  한 명은 부모 역, 한 명은 관찰자 역 후 교대).
- Unity 전환 여부 판단(웹 3D 한계 실측 기준), 별도 앱 'BlueHarmony Play' 분리 검토.
- B2G 실습 패키지: 육아종합지원센터·유치원 부모교육의 실습 도구 버전(강사 대시보드 포함).

### 3.3 비용·성능 예산

- LLM: 퀘스트당 LLM 호출 6~10회 → 짧은 컨텍스트(상태 요약만 전달) + 반응 모드는 상태머신이
  결정해 토큰 절약. 목표: 퀘스트당 원가를 구독 일할(₩330/일)의 절반 이하로.
  무료 유저는 일 1퀘스트 제한, 사전 생성 대사 뱅크 비중 확대.
- 3D: 로우폴리(아바타 15k tri 이하, 씬 50k 이하), 텍스처 아틀라스, 저사양 폰은 그림자·후처리
  자동 오프. PWA 최초 로드는 씬 지연 로드로 본체 성능에 영향 주지 않게.
- 지연: 아이 반응 첫 표시 1.5초 목표 — 표정·몸짓(상태머신, 0ms)이 먼저 나오고 대사(LLM)가
  따라오는 연출로 체감 지연을 숨긴다. (몸이 먼저 반응하는 게 오히려 사실적이다)

## 4. 방향성 — 사업에서의 위치

### 4.1 세그먼트 확장

| 세그먼트 | 시뮬이 여는 것 |
|---|---|
| 기존: 3~9세 부모 | 연습 모드 = 구독 가치 강화, 사춘기 미리보기 = 업셀 |
| **신규: 예비 부모** | 아이가 없어도 쓸 수 있는 첫 블루하모니 — TAM 확장. 표준 기질 프리셋으로 플레이 |
| **신규: B2G/B2B 교육** | 부모교육 '실습' 도구 — 강의식 교육의 고질적 한계(듣고 잊음)를 실습으로 해결. 시뮬 수료 데이터 = 기관용 리포트 |
| 신규: 교사·돌봄 인력 연수 | 기질별 대응 훈련 — 유보통합 시대의 교사 연수 콘텐츠 |

### 4.2 수익 구조 (본체 구독에 통합, 별도 과금 최소화)

- 무료: 현재 연령 밴드 일 1퀘스트, 방 꾸미기 기본.
- 플러스(기존 ₩9,900): 전 밴드 무제한, **사춘기 미리보기**, 부부 협동 퀘스트, 추억 앨범 무제한.
- B2G: 기관 라이선스(실습 시트 + 강사 대시보드) — Phase 2 영업 파이프라인에 합류.
- 원칙 유지: 확률형 없음, 능력치 판매 없음, 위기 관련 콘텐츠 무료.

### 4.3 데이터 플라이휠에서의 역할

시뮬은 **개입 정책의 실험실**이다. 현실에서는 A/B 테스트할 수 없는 것(같은 상황에 다른
대응)을 시뮬에서는 수만 번 관찰할 수 있다: 어떤 기질 조합에서 부모가 어떤 개입을 고르는지,
어디서 막히는지, 회복 루프를 배우는 속도가 어떤지. 이 데이터는 ①코치 스크립트 개선
②검사 문항 타당화 보조 ③PARAN AI의 개입 정책 학습장이 된다. — 03-ai-engine의 데이터
전략(D1~D4)에 시뮬 로그가 새 원천으로 추가되는 것.

### 4.4 전이 지표 — 시뮬의 존재 증명

**노스스타(시뮬)**: "연습한 상황의 실전 승률 리프트" — 시뮬에서 연습한 상황 카테고리의
실제 SOS '먹혔다'율 vs 연습 안 한 카테고리의 차이. 이 숫자가 양수로 증명되는 순간,
- 유저에겐 "연습이 통한다"는 구독 사유가 되고,
- B2G에는 "실습형 부모교육의 효과 데이터"라는 영업 자료가 되고,
- 투자자에겐 학습 효과가 측정되는 에듀테크라는 내러티브가 된다.

### 4.5 리스크

| 리스크 | 심각도 | 대응 |
|---|---|---|
| 스코프 폭발 (1인 팀이 게임 개발) | **치명** | S0 게이트 전 3D 금지, 씬 1개·아바타 1종 원칙, V2 본체와 릴리즈 트랙 분리 |
| 모바일 게임 눈높이 미달 ("이게 게임?") | 높음 | '게임'이 아니라 '시뮬레이터·연습'으로 포지셔닝 — 비교 대상을 원신이 아니라 부모교육 강의로 만든다 |
| 불쾌한 골짜기·정서 전이 | 높음 | 스타일라이즈드 고정, 실물 사진 이식 금지, 디브리핑에서 "가상 아이" 명시 |
| LLM 원가 | 중간 | 상태머신 우선 아키텍처, 대사 뱅크 캐시, 무료 일 1퀘스트 |
| "게임이 현실 육아를 대체" 비판 | 중간 | 전이 지표 공개, 퀘스트 말미 "오늘 실전에서 한 번" 미션으로 현실 연결 고정 |
| 심의·규제 (게임물, 아동 콘텐츠) | 낮음 | 앱 내 모드로 시작(마켓 자체등급분류), 확정형 보상만, 사행성 전무 |
