## 1. 게임물 분류 — 전제 이슈 (상)

가상융합산업 진흥법(2024.8.28 시행)은 진흥법이지 게임산업법 적용을 배제하는 면제법이 아니다. 이 앱의 **별점(점수) → 리워드(재화) → 파워랭킹(경쟁) → 분기 시상(보상)**은 게임산업법 §2 게임물 정의에 매우 가깝고, 게임물 판정 시 ①등급분류 의무 ②사행성 규제(§28) ③환전 금지(§32) ④확률형 아이템 공시 의무가 전부 적용된다.

**대응 전략 — "게임물로 판정된다"를 기본 전제로 설계한다.** 리듬 판정·앙코르 게이지·시즌패스·랭킹 리셋 등 명백한 게임 메커니즘을 채택하는 이상, '게임적 어휘 배제'식 회피는 실효성이 낮다. 폐쇄 루프·환전 금지를 처음부터 준수하면([03 §6](./03-economy-design.md)) 어느 쪽으로 판정돼도 안전하다.
- 모바일 앱은 구글/애플 자체등급분류사업자 경로로 등급분류 부담이 크지 않다.
- **주의 — 웹 배포와의 충돌**: 웹 MVP는 앱마켓 자체등급분류 유통망 밖이라 게임물 판정 시 게임위 직접 등급분류가 필요할 수 있다. **웹 MVP 단계에서 게임물 판정 가능성 × 배포 채널 조합을 게임법 전문 로펌 자문으로 확인할 것**(기획 단계 최우선 실행 항목). 필요 시 게임위 사전 질의.

## 2. 리워드의 법적 지위 (상)

- '별점 매기면 리워드'는 노력 기반 보상이라 우연성이 약해 그 자체로 사행행위는 아니다. **진짜 위험은 환가성**: 게임물 판정 시 §28(사행성 조장 금지)·§32①7(게임머니 환전·알선·재매입 금지)에 정면으로 걸린다.
- **전금법**: 2024.9.15 시행 개정법에서 '2개 이상 업종' 요건이 삭제되어 단일 서비스 전용 충전 재화도 규제 대상. 등록 면제는 "발행잔액 30억 미만 **AND** 연간 총발행 500억 미만" 둘 다 충족해야 한다. 단, **무상 지급 포인트는 '대가를 받고 발행'한 것이 아니므로 선불전자지급수단이 아니다 — 이것이 설계의 핵심 탈출구.**
- **안전 설계**(채택안): ①이중 재화 분리(상호 교환 전면 금지 — 유료→무료 단방향 전환도 금지: 전환분이 '대가를 받고 발행'이 되어 면제 논리가 깨짐) ②SP 완전 폐쇄 루프 ③아티스트 정산은 재화가 아닌 별도 '크리에이터 수익 배분 프로그램'(유튜브 파트너 방식, 원천징수 포함) ④약관에 SP의 재산적 가치 부인 + 유효기간 명시.

## 3. 분기 어워드 보상 (중)

- 소비자현상경품 고시 2016년 폐지로 일반 경품 상한 규제는 없음. 기량·성과 시상은 원칙적으로 적법.
- 다만: ①게임물 판정 시 §28과 충돌 가능 ②기준 불명확·과장 시 표시광고법 ③민법 §675 현상광고로서 조건·기간 사전 공지 후 임의 변경 불가 ④5만원 초과 상금은 기타소득 원천징수 의무 ⑤어뷰징으로 조작된 순위에 고액 보상이 지급되면 손해배상·업무방해 분쟁(아이돌 투표 조작 유형).
- **완화**: 산식·기간·실격 조항 사전 공표 + 약관 편입, 초기(Phase 1)에는 현금 대신 명예·앱 내 혜택 중심([03 §5](./03-economy-design.md)).

## 4. AI 생성 음악 저작권 (상)

### 소송 동향 (2026.7 기준)
- UMG–Udio 합의(2025.10, 라이선스 플랫폼 공동 출시), WMG–Udio·Suno 합의(2025.11). 그러나 **Sony Music은 양사와 소송 계속 중, UMG v. Suno도 진행 중** — 침해 대상 61,026곡으로 확대 신청, 잠재 배상 90억 달러+. 독립 아티스트 집단소송(Nguyen v. Suno)도 제기.
- 시사점: "Suno로 만들었으니 안전"이라는 유저 인식은 틀렸다. **AI 곡이 기존 곡과 실질적으로 유사하게 출력되는 사고가 플랫폼에서 터질 수 있다.**

### 한국 제도
- **KOMCA는 2025.3.24부터 AI가 일부라도 관여한 곡의 신탁 등록을 거부**(세계 최고 수준 엄격).
- 문체부·저작권위원회 안내서(2025.6): 인간의 창작적 기여 부분만 등록 가능. **AI 100% 곡은 한국법상 저작권이 없는 무주(無主) 콘텐츠** — 유저가 "내 곡"이라 주장해도 타인의 복제를 저작권으로 막을 수 없고, 앱 내 독점권은 약관(계약)으로만 구성해야 한다.

### 플랫폼 면책 구조 (커버·표절 대응)
- 저작권법 §102 OSP 면책 요건: ①통지 시 즉시 삭제(notice & takedown) ②반복 침해자 계정 해지 정책 ③권리자 신고 창구 상시 운영. 미비 시 침해 방조 책임(소리바다 판례 계열). KOMCA 신탁곡 커버의 '공연+전송'은 사용료 징수 대상이 되어 플랫폼에 청구될 수 있다 → **커버곡은 정책적으로 금지**(자작곡·오리지널 한정).
- **방어 체계**: ①ACRCloud 핑거프린트 + 커버 인식 모드 자동 검사 ②업로드 시 권리 보증 체크(본인 창작/AI 사용 툴/제3자 권리 없음 + 위반 시 면책·구상 조항) ③AI 곡 'AI 제작' 라벨 의무화(한국 AI기본법 2026.1 시행 정합) ④신고 후 24~48시간 내 삭제 SLA + 삼진아웃 ⑤Suno 곡은 '유료 티어 생성' 자가 확인([02 §6](./02-development-plan.md)).

## 5. 별점 어뷰징 (상)

예상 공격: ①매크로·다계정 자기 별점(리워드 이중 수취) ②품앗이 담합 ③경쟁자 1점 테러. 드루킹 판례(컴퓨터등장애업무방해죄)로 사후 법적 대응 근거는 있으나 **시스템 설계가 본질**.

방어: 참석 증빙 기반 평가권(60%+ 실재) / 신뢰도 가중 베이지안 평균 / 기기지문·IP 클러스터 상호 평가 자동 무효화 / 리워드 일일·주간 상한 / 시상 직전 이상 탐지 강화 + 실격·회수 약관. 정량 스트레스 테스트(품앗이 기대 시급을 최저임금의 14% 이하로 억제)는 [03 §3](./03-economy-design.md) 참조.

## 6. 미성년자 보호 (상)

- 제페토에서 아바타 성희롱·스토킹·"아이템 줄게" 그루밍으로 성착취물을 제작한 사건이 실제 다수 보도됨. 음성이 있는 콘서트 앱은 노출면이 더 크다. 아청법 §15의2(온라인 그루밍 처벌) 시행 중.
- 개인정보보호법상 만 14세 미만은 법정대리인 동의 필요(확인 의무는 사업자에게).
- **완화**: ①초기에는 **만 14세 이상만 가입 허용**(동의 체계·아동 모더레이션 부담 원천 차단) ②퍼스널 바운더리 기본 활성화(Meta Horizon Worlds 방식 아바타 최소 거리) ③원터치 신고·즉시 차단·음소거 ④신고 시 직전 N분 음성 버퍼 첨부(Rec on report) + 금칙어·그루밍 패턴 필터 + 24시간 처리 SLA ⑤확장 시 청소년보호책임자 지정, 성범죄 의심 건 즉시 수사기관 통보 프로세스 문서화.

## 7. 운영 리스크 (중~상)

- **스파이크형 트래픽**: 공연 시각 폭주 구조. 실시간 3D + 음성은 Vercel 서버리스로 불가 — 별도 게임서버 필수. 인기 공연이 겹치면 월 수백만 원 청구 가능 → 인스턴스 자동 스케일 상한, 공연 사전 예약제로 수요 예측, **관객 수 티어별 대관료(SP)로 수요 자체를 경제 시스템 안에서 조절**.
- **음원 검수 병목**: 유저당 최대 15곡 × 유저 수만큼 선형 증가. 1차 ACR 자동 필터 + 신고 기반 2차 인력 검수 + 통과 전 비공개 대기열. 검수 지연 = 창작자 이탈이므로 SLA(48시간)를 공개 지표로 관리.
- **모더레이션 인력**: 실시간 음성 공연은 텍스트 대비 고비용 → 초기에는 공연 개설 권한을 신뢰 등급제로 단계 개방해 모더레이션 대상 자체를 축소.

## 8. 기술 리스크 (상)

소규모 팀이 **물리엔진 + 대규모 동접 + 공간오디오**를 동시에 정면 구현하는 것은 업계 최상위 난이도 조합이다.

1. **네트워크 물리 동기화 함정**: 수천 명 물리를 서버 권위로 동기화하면 대역폭·틱레이트 폭발 → **물리는 로컬 연출로 한정**, 네트워크는 이벤트만 전송. 서버 권위 물리는 아예 쓰지 않는 것이 정답에 가깝다.
2. **'대규모 동접'의 실상**: Travis Scott 콘서트(1,230만 명)조차 인스턴스당 ~50명 샤딩. 단일 월드 수천 명은 스타트업이 도전할 문제가 아니다 → 인스턴스 분할 + 고스트 관중(타 인스턴스 관객 실루엣 표시)이 표준 패턴.
3. **공간오디오 + 실시간 음성**: 음원 재생의 공간감은 성숙 영역(Web Audio HRTF/FMOD)이나, 실시간 음성 채팅을 얹으면 비용·복잡도 급증 → 초기에는 음성을 소규모 존으로 제한.
4. **생존 범위**: MVP는 "소규모 룸(30~50명) + 로컬 물리 연출 + HRTF 공간 음원 + 텍스트 응원"으로 잘라야 생존 가능하다. 상세는 [02](./02-development-plan.md).
