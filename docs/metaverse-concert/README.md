## 핵심 결론 요약

- **전략**: "메타버스 플랫폼"이 아니라 **"아마추어 창작자의 무대 + 관중→아티스트 성장 서사"라는 버티컬**로 좁힌다. 범용 메타버스는 이프랜드(2025.3 종료)·컴투버스가 증명한 실패 경로다.
- **기술**: MVP는 **웹 기반(React Three Fiber + Rapier + Web Audio + Colyseus)**으로 3~4개월 내 핵심 루프 검증 — 기존 Next.js+Supabase 스택을 플랫폼 백엔드로 재활용. 검증 후 Unity 병행을 결정.
- **경제**: 무상 리워드(SP)는 완전 폐쇄 루프로 설계해 게임산업법 환전 금지·전금법 선불업 규제를 동시 회피. 유료 재화 → SP 전환은 금지(법적 방어선).
- **최대 리스크**: ① 게임물 분류 판정 가능성(법률 자문 필수) ② AI 음악 저작권(Sony/UMG 소송 진행 중, KOMCA는 AI 곡 등록 거부) ③ 별점 어뷰징(= 화폐 발행 장치) ④ 텅 빈 공연장(콜드스타트).
- **사업성 판정**: 니치 커뮤니티 서비스로서 생존 가능성 중간, 대형 플랫폼화는 저확률-고보상. 성립 조건 4가지 — 오가닉 유입 비중 70%+, 슈퍼팬 과금으로 ARPU ₩1,500+, 손익분기 전 번레이트 월 ₩2,000만 이하, 일본 확장 파일럿 선행. 18개월 총 소요 약 ₩7.5억.
