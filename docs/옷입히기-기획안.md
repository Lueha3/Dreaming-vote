# 옷입히기 AI 프로그램 기획안

> 초등학생도 이해할 수 있게 쓴 버전입니다.
> (어른/개발자용 자세한 내용은 맨 아래 **부록**에 있어요.)

---

## 1. 한 줄로 말하면?

**"종이인형 옷 갈아입히기 놀이"를 진짜 사진으로 하는 프로그램**입니다.

사람 사진 한 장을 넣고, 옷 사진을 몸에 **끌어다 붙이면(드래그)**,
AI가 그 옷을 진짜로 입은 것 같은 **사진**과 **짧은 영상**을 만들어 줍니다.

```
[사람 사진]  +  [옷 사진들]  →  🤖 AI  →  [입은 사진] + [움직이는 영상]
```

---

## 2. 왜 필요할까요?

| 이런 사람에게 | 이렇게 좋아요 |
|---|---|
| 옷을 사기 전에 고민되는 사람 | 입어보지 않고도 어울리는지 미리 봐요 |
| 옷을 파는 사람 | 모델을 부르지 않고 착용 사진을 만들어요 |
| SNS에 올리고 싶은 사람 | 사진 + 영상까지 한 번에 나와요 |

---

## 3. 화면은 이렇게 생겼어요

```
┌─────────────────────────────────────────────────────────┐
│  옷입히기                                [만들기 ▶]      │
├───────────────┬─────────────────────────┬───────────────┤
│  옷장 (왼쪽)   │     사람 사진 (가운데)     │  설정 (오른쪽) │
│               │                         │               │
│  👕 티셔츠     │        ┌───────┐        │  🎨 깔맞춤 톤  │
│  🧥 아우터     │        │  🙂   │        │               │
│  ⌚ 시계       │        │ 사람  │        │  색깔: 네이비  │
│  👜 가방       │        │ 사진  │        │  채도: 진하게  │
│  ─────────    │        └───────┘        │               │
│  👖 바지       │   ↑ 여기로 옷을 끌어옴   │  적용할 부위:  │
│  👟 신발       │                         │  ☑ 상의       │
│  🎗 벨트       │                         │  ☑ 벨트       │
│               │                         │               │
└───────────────┴─────────────────────────┴───────────────┘
```

- **왼쪽 = 옷장**: 내가 가진 옷 사진들이 모여 있는 곳
- **가운데 = 무대**: 사람 사진이 놓이는 곳
- **오른쪽 = 설정**: 색깔 맞추기 같은 세부 조절

## 4. 사용하는 순서 (5단계)

### ① 사진 넣기
사람 사진을 **한 장** 올립니다. (드래그해서 넣거나, 클릭해서 고르기)

### ② 작업할 부분 정하기
사진 위에서 **네모를 그려(드래그)** "여기에 옷을 입힐 거야!" 라고 알려줍니다.

- 사진에 사람이 **두 명**이면? → 네모를 **두 개** 그리면 됩니다.
  (왼쪽 모델 / 오른쪽 모델 이렇게 따로 꾸밀 수 있어요.)

```
   드래그 전                  드래그 후
   ┌──────────┐             ┌──────────┐
   │  🙂  🙂  │    ──▶      │ ┌─┐  ┌─┐ │
   │ 사람 사람 │             │ │1│  │2│ │  ← 1번 모델, 2번 모델
   └──────────┘             │ └─┘  └─┘ │
                            └──────────┘
```

### ③ 옷 끌어다 붙이기
옷장에서 옷 사진을 골라 **몸의 알맞은 자리**에 끌어다 놓습니다.
자리에 가까이 가면 **그 부위가 반짝** 하고 표시돼요. 놓으면 착! 붙습니다.

붙일 수 있는 자리는 **7군데**입니다.

| 그룹 | 부위 | 어디에 놓나요? |
|---|---|---|
| **상의** | 👕 티셔츠 | 가슴·배 부분 |
| | 🧥 아우터 | 어깨·팔 부분 |
| | ⌚ 시계 | 손목 |
| | 👜 가방 | 어깨 또는 손 |
| **하의** | 👖 바지 | 허리 아래 ~ 발목 |
| | 👟 신발 | 발 |
| | 🎗 벨트 | 허리 |

> 규칙: **한 자리에는 한 개만** 놓입니다. 이미 옷이 있으면 새 옷으로 바뀌어요.
> 잘못 놓았으면 옷을 **밖으로 끌어내면** 벗겨집니다. (되돌리기 버튼도 있어요)

### ④ 깔맞춤 톤 고르기 (핵심 기능! → 5번에서 자세히)
"색깔을 맞춰서 예쁘게" 만드는 단계입니다. 안 해도 됩니다(선택).

### ⑤ 만들기 버튼 누르기
AI가 일합니다. 잠깐 기다리면 **사진**과 **짧은 영상**이 나옵니다.

## 5. 깔맞춤 톤 선택 (자세히)

**깔맞춤이 뭐예요?**
👉 옷 색깔을 서로 맞춰서 "한 세트처럼" 보이게 하는 것입니다.
예) 모자와 신발을 똑같이 검정으로 → 깔끔해 보임 😎

### 1단계 — 색깔과 진하기 고르기

```
색깔 고르기:  🔴 🟠 🟡 🟢 🔵 🟣 ⚫ ⚪ 🟤   ← 네이비 선택!
진하기(채도): ○──────●──────○
             연하게   보통   진하게
```

- **색깔** = 무슨 색인지 (빨강, 파랑, 네이비…)
- **채도** = 그 색이 얼마나 진한지 (물감에 물을 많이 탈수록 연해져요 🎨)

### 2단계 — 어디에 칠할지 안내선(가이드라인) 보여주기

색깔을 고르면, 사진 위에 **"여기 클릭할 수 있어요!"** 하고 부위마다 표시가 뜹니다.
7군데 **모두** 고를 수 있고, **여러 개**를 골라도 됩니다.

```
   ┌ ─ ─ ─ ─ ─ ┐   ← 점선 = 고를 수 있는 자리
   │  [상의]   │      클릭하면 색이 칠해짐 ✅
   │  [벨트]   │
   │  [하의]   │
   └ ─ ─ ─ ─ ─ ┘
```

### 3단계 — 모델마다 다르게 골라도 돼요

예시) **네이비**를 고른 뒤…

| | 네이비를 칠할 부위 |
|---|---|
| 👈 **왼쪽 모델** | 상의 + 벨트 |
| 👉 **오른쪽 모델** | 하의 + 시계 |

이렇게 하면 두 사람이 **커플룩처럼** 색을 나눠 가진 느낌이 납니다.

### 4단계 — 미리보기 → 만들기
색이 칠해진 모습을 작게 미리 보여주고, 마음에 들면 **[만들기]**를 누릅니다.

## 6. 결과물

만들기를 누르면 두 가지가 나옵니다.

| 결과 | 내용 |
|---|---|
| 🖼 **이미지** | 옷을 입은 사진 (여러 장 중 마음에 드는 걸 고르기) |
| 🎬 **영상** | 3~5초짜리 짧은 영상 (한 바퀴 돌기 / 걷기 등 움직임 선택) |

버튼: **[저장하기]** **[공유하기]** **[다시 만들기]**

## 7. 이럴 땐 이렇게 (문제 해결)

| 이런 일이 생기면 | 프로그램이 이렇게 알려줘요 |
|---|---|
| 사람이 안 보이는 사진을 넣음 | "사람이 잘 보이는 사진을 넣어 주세요" |
| 옷을 엉뚱한 자리에 놓음 | 자석처럼 **가장 가까운 알맞은 자리**로 붙여줌 |
| 티셔츠를 발에 놓으려 함 | 그 자리는 **회색**으로 변하며 놓이지 않음 |
| 아무것도 안 붙이고 만들기 | "옷을 한 개 이상 붙여 주세요" |
| AI가 만드는 중 | 진행 막대 표시 (예: 40% … 잠시만요!) |
| 만들기 실패 | "다시 시도" 버튼 표시 |

## 8. 만드는 순서 (개발 단계)

| 단계 | 목표 | 할 일 |
|---|---|---|
| **1차** | 붙이는 것까지 | 사진 올리기 → 영역 드래그 → 옷 7부위 드래그 부착 |
| **2차** | 이미지 만들기 | AI로 착용 이미지 생성 |
| **3차** | 깔맞춤 톤 | 색·채도 선택 + 부위 가이드라인 + 모델별 적용 |
| **4차** | 영상 만들기 | 이미지 → 3~5초 영상 |
| **5차** | 다듬기 | 저장·공유, 여러 명 동시 작업, 속도 개선 |

# 📎 부록 (개발자용)

## A. 화면 상태 흐름

```
UPLOAD → SELECT_AREA → DRESS → (TONE) → GENERATING → RESULT
  ↑                                                     │
  └──────────────── 다시 만들기 ────────────────────────┘
```

## B. 데이터 모델(초안)

```ts
type Slot =
  | 'top'      // 티셔츠
  | 'outer'    // 아우터
  | 'watch'    // 시계
  | 'bag'      // 가방
  | 'pants'    // 바지
  | 'shoes'    // 신발
  | 'belt';    // 벨트

const SLOT_GROUP: Record<Slot, 'upper' | 'lower'> = {
  top: 'upper', outer: 'upper', watch: 'upper', bag: 'upper',
  pants: 'lower', shoes: 'lower', belt: 'lower',
};

interface ModelArea {
  id: string;                 // 모델 1, 모델 2 …
  bbox: { x: number; y: number; w: number; h: number }; // 사용자가 드래그한 영역(정규화 0~1)
  items: Partial<Record<Slot, ClothingItem>>;           // 슬롯당 1개
  tone?: ToneSelection;
}

interface ClothingItem {
  id: string;
  slot: Slot;
  imageUrl: string;
}

interface ToneSelection {
  hue: string;        // 예: '#1B2A4A' (네이비)
  name: string;       // 'navy'
  saturation: number; // 0~100
  targets: Slot[];    // 예: ['top', 'belt']
}

interface Project {
  baseImageUrl: string;
  areas: ModelArea[]; // 여러 모델 지원
}
```

## C. 드래그 부착 규칙

1. 드롭 위치에서 **가장 가까운 슬롯 히트박스**를 찾는다(스냅 반경 내).
2. 슬롯 타입과 아이템 타입이 다르면 **거부**(커서 `not-allowed`, 히트박스 회색).
3. 같은 슬롯에 이미 아이템이 있으면 **교체**하고 Undo 스택에 이전 상태를 push.
4. 슬롯 히트박스는 사용자가 그린 `bbox`를 기준으로 **비율 계산**(예: 상의 = 상단 20~55%, 신발 = 하단 90~100%).
   - 자세 추정(pose estimation)을 붙이면 정확도가 올라가지만 1차에서는 비율 방식으로 충분.

## D. AI 파이프라인

| 순서 | 처리 | 비고 |
|---|---|---|
| 1 | 옷 이미지 배경 제거 | `remove_background` 계열 |
| 2 | 슬롯별 마스크 생성 | bbox 비율 or pose 기반 |
| 3 | 톤 적용 프롬프트 합성 | `targets` 슬롯에 hue/saturation 반영 |
| 4 | 착용 이미지 생성 | image-to-image + 마스크 인페인팅 |
| 5 | 결과 이미지 → 영상 | image-to-video, 3~5초, 카메라/포즈 프리셋 |

**프롬프트 조립 예시**

```
{모델 설명}이(가) {아이템 목록}을 착용.
톤 지시: {targets} 부위를 {name}({hue}) 색, 채도 {saturation}%로 통일.
그 외 부위의 색상·질감은 원본 유지. 얼굴/체형/배경 변경 금지.
```

## E. 비기능 요구사항

- 생성 대기 시간: 이미지 30초 이내, 영상 2분 이내 목표 (초과 시 진행률 + 백그라운드 알림)
- 실패 시 자동 재시도 1회, 이후 사용자에게 "다시 시도" 노출
- 원본 사진은 생성 후 N일 뒤 자동 삭제(개인정보), 업로드 시 안내 문구 노출
- 얼굴이 포함된 타인 사진 업로드 금지 안내 및 동의 체크
