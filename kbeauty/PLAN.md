# Seoulmate — 글로벌 K-뷰티 성분 매칭 & 역직구 플랫폼 기획안

> **한 줄 정의**: 해외 소비자가 한국 화장품을 카메라로 스캔하면, 성분을 영어(INCI)로 번역·안전등급 분석하고 본인의 기후·피부 타입과의 궁합을 알려준 뒤, 그 자리에서 역직구 결제까지 이어주는 반응형 모바일 웹 서비스.

- **워킹 타이틀**: `Seoulmate` (Seoul + Soulmate — "너의 K-뷰티 소울메이트") · 대안: GlowDex, Ingrely, SkinSeoul
- **형태**: 반응형 모바일 웹 (PWA) — 앱스토어 없이 링크 하나로 Reddit/TikTok에서 즉시 유입
- **스택**: Next.js(App Router) + Vercel + Supabase + Google Cloud Vision OCR + Stripe/PayPal

---

## 1. 문제 정의와 기회

| 문제 | 근거 |
|---|---|
| 한국 화장품 성분표가 한글이라 해외 소비자가 읽을 수 없음 | 올리브영 매장·직구 제품 뒷면은 전량 한글 전성분 |
| '화해'급 성분 분석 서비스의 영어판이 존재하지 않음 | 화해는 국내 전용, INCIDecoder는 K-뷰티 커버리지·한글 OCR 없음 |
| 해외 유저는 Reddit r/AsianBeauty, 틱톡 댓글에 의존 | 정보가 파편화, 신뢰도 검증 불가 |
| 본인 기후(동남아 다습, 북미 건조)와 제품 궁합을 알 방법이 없음 | 기존 성분 앱 어디에도 기후 변수 없음 → **핵심 차별화** |
| 알게 되어도 구매 경로(올영 글로벌)의 배송비 장벽이 큼 | 분석 → 구매 사이의 전환 공백 = 우리의 수익 구간 |

**전략 요약**: 커머스로 시작하지 않는다. "영어권 소비자를 위한 무료 K-뷰티 성분 가이드 툴"로 신뢰를 먼저 쌓고, 트래픽이 확보되면 분석 결과 하단에 역직구 결제창을 연다.

## 2. 타깃 페르소나

1. **Skincare Nerd (북미/유럽, 20~35)** — r/AsianBeauty 구독자. 성분표를 직접 읽고 싶어함. 레티놀·나이아신아마이드 농도까지 따짐. → OCR 번역 + EWG 등급이 킬러 기능.
2. **TikTok Follower (글로벌, 16~28)** — 인플루언서가 쓰는 제품을 그대로 사고 싶음. 성분은 "안전한지"만 확인. → 스캔 → 적합도 점수 → 원클릭 구매 동선이 킬러.
3. **동남아 공구 참여자 (SEA, 20~40)** — 총대(개인 셀러) 통해 구매. 다습 기후에서 모공 막힘 걱정. → 기후 궁합 지수 + 배송비 N분의 1이 킬러.

## 3. 핵심 기능 (MVP)

### 3.1 스마트 성분 스캐너 (OCR + 바코드)
- 한글 전성분 사진 → Google Cloud Vision OCR → 한글 성분명 → INCI 영어 표준명 매칭 → 성분 카드 리스트.
- **제안: 바코드 스캔을 1차 경로로.** 바코드 → 제품 DB 직매칭이 OCR보다 정확·빠름. OCR은 DB에 없는 제품의 폴백 + DB를 채우는 크라우드소싱 수단(유저가 스캔한 라벨이 곧 데이터 수집).
- 매칭 실패 성분은 "검수 대기" 큐로 → 운영자가 확정 → DB가 스스로 자람.

### 3.2 기후 × 피부 맞춤 궁합 지수 (차별화 핵심)
- 온보딩: 국가/도시(→ 기후 프로필 자동), 피부 타입(바우만 16타입 축약 퀴즈 4문항), 민감 성분(향료·에센셜오일 등).
- 성분 배합 속성(폐색성/코메도제닉 지수, 휘발성, 습윤제 비율)을 기후(습도·온도·UV)와 교차해 0~100 **Match Score** 산출.
- 결과 예: "싱가포르의 고온다습 기후에서는 이 크림의 오클루시브 비율이 높아 모공 막힘 위험 — 젤 타입 대안 3개 추천".

### 3.3 클린 뷰티 필터
- EWG 위험 등급, 비건, 크루얼티프리, 무향료, 임산부 주의 성분을 자동 파싱해 뱃지로 시각화.
- 유저별 "내 기피 성분" 목록 → 스캔 즉시 빨간 경고.

### 3.4 역직구 커머스 (Phase 2)
- 분석 결과 하단 "Ship it to 🇸🇬 $X.XX" 버튼 → 크로스보더 드롭쉬핑(국내 도매/브랜드사 소싱 + 풀필먼트 대행).
- **배송비 N분의 1 취합**: 국가별 주간 배치 — "이번 주 싱가포르행 박스 6/8명 참여, 1인당 $3.20" 실시간 게이지로 참여 유도(마감 임박 심리).
- 결제: Stripe(카드) + PayPal, 이후 포트원 해외결제로 로컬 결제수단(GrabPay 등) 확장.

## 4. 추가 제안 기능 (제가 권하는 것들)

| 기능 | 설명 | 왜 |
|---|---|---|
| **루틴 충돌 검사기** | 내 화장대(Shelf)에 담긴 제품끼리 궁합 검사 — "레티놀 + AHA 같은 밤에 쓰지 마세요" | 리텐션의 핵심. 스캔 1회 앱 → 매일 쓰는 앱으로 전환 |
| **Dupe Finder** | 비싼 서구 브랜드 제품과 성분 유사도가 높은 저렴한 한국 대체품 추천 | 틱톡 바이럴 포맷 그 자체("$68 에스티로더 vs $14 K-뷰티 듀프") → 자연 유입 + 즉시 커머스 전환 |
| **피부 쌍둥이(Skin Twin) 리뷰** | 리뷰를 기후·피부타입이 나와 같은 유저 것만 필터링 | 별점 5.0보다 "나와 같은 지성+다습 유저의 4.2"가 구매 전환에 강력 |
| **위시리스트 → 재입고/배치 알림** | 담아둔 제품이 내 국가행 주간 배치에 포함되면 웹푸시 | 커머스 전환 트리거. PWA 웹푸시로 구현 가능 |
| **PAO(개봉 후 사용기한) 알림** | 스캔한 제품의 6M/12M 기한 추적 → 만료 임박 시 재구매 제안 | 자연스러운 재구매 루프 |
| **AI 성분 챗** | "이거 임산부가 써도 돼?" 자유 질문 (성분 DB 그라운딩 + LLM) | Reddit에서 오가는 Q&A를 제품 안으로 흡수 |
| **크리에이터 대시보드** | 인플루언서별 전용 링크/할인코드 + 실시간 커미션 정산 조회 | GTM 2단계(틱톡 앰버서더)의 인프라. 수기 정산은 스케일 불가 |
| **점수 공유 카드** | 스캔 결과를 예쁜 OG 이미지로 생성 → 틱톡/레딧 공유 | 유저가 마케팅을 대신하게 하는 바이럴 루프 |

> 우선순위 제안: MVP에 **공유 카드**(공수 작고 바이럴 직결)와 **Shelf(화장대) 저장**(리텐션)까지만 포함. Dupe Finder·충돌 검사기는 성분 DB가 5천 개 이상 쌓인 Phase 2에.

## 5. 비즈니스 모델

1. **역직구 물류 마진** (핵심): 소싱가 대비 15~25% + 배송 취합 수수료
2. **어필리에이트 레비뉴 쉐어**: 크리에이터 코드 매출의 10~15%를 분배, 나머지가 우리 마진
3. **B2B 총대 솔루션** (Phase 3): 공구 셀러에게 추천 리포트 발행 + 원스톱 물류 → 월 구독 + 건당 수수료
4. (장기) 국내 인디 브랜드 대상 "글로벌 반응 데이터" 리포트 판매

## 6. 기술 아키텍처

```
[모바일 웹 (Next.js PWA, Vercel)]
   ├─ 카메라 캡처 → /api/scan ─→ Google Cloud Vision OCR
   │                              └→ 한→INCI 매칭 엔진 (Supabase RPC + 유사도 검색)
   ├─ Match Score 엔진 (Edge Function: 성분속성 × 기후 × 피부프로필)
   ├─ Supabase ── Auth(소셜) / Postgres / Storage(라벨 이미지) / Realtime(배치 게이지)
   ├─ 결제: Stripe + PayPal → 주문 → 풀필먼트 파트너 API
   └─ 웹푸시(PWA) · OG 이미지 생성(@vercel/og)
```

- **성분 DB 소싱 전략(중요)**: EWG 등급 데이터는 저작권 있음 — 그대로 크롤링 금지. ① EU **CosIng**(공개 DB)로 INCI 표준명·기능 확보 ② 식약처 화장품 성분사전(공공데이터)으로 한글↔INCI 매핑 ③ 위험도는 CIR/SCCS 공개 평가 기반 **자체 등급**으로 산출하고 "EWG 스타일" 표기 대신 자체 명칭 사용. 법무 리스크 제거 + 자산화.
- **기후 데이터**: 도시별 월평균 습도/온도/UV 정적 테이블이면 충분(실시간 API 불필요, Phase 2에 Open-Meteo 연동).

### 데이터 모델 (요약)

```
users ─ skin_profiles(type, concerns, avoid_ingredients[], city→climate_id)
climates(city, humidity_band, temp_band, uv_band)
products(barcode, brand, name_ko, name_en, category, images)
ingredients(inci_name, name_ko, functions[], comedogenic, safety_grade, flags{vegan,fragrance,preg_caution})
product_ingredients(product_id, ingredient_id, order)
scans(user_id, image_url, ocr_raw, matched_product_id, status)
analyses(scan_id, match_score, breakdown_json)
shelves(user_id) / shelf_items
orders / order_items / group_shipments(country, week, target_n, joined_n, per_head_fee)
creators(code, revshare_pct) / referrals(order_id, creator_id, commission)
reviews(user_id, product_id, rating, body, skin_snapshot_json)
```

## 7. 개발 로드맵

| Phase | 기간 | 산출물 |
|---|---|---|
| **0. 랜딩+웨이트리스트** | 1~2주 | 본 프로토타입 기반 랜딩 배포(Vercel), 이메일 수집, Reddit 반응 테스트 |
| **1. MVP 스캐너** | 4~6주 | 온보딩 퀴즈 → 바코드/OCR 스캔 → 성분 번역 → Match Score → 공유 카드 → Shelf. 성분 DB 시드 3천 개(인기 제품 500개 수작업 검수) |
| **2. 커머스** | 4주 | 제품 상세 → Stripe/PayPal 결제 → 드롭쉬핑 오퍼레이션 → 배송비 N분의 1 배치 시스템 → 크리에이터 코드 |
| **3. 커뮤니티/B2B** | 6주+ | Skin Twin 리뷰, Dupe Finder, 충돌 검사기, 총대 B2B 대시보드, 로컬 결제수단 |

**Phase 1 스프린트 세부(6주)**: W1 스키마+성분 DB 파이프라인 → W2 온보딩+프로필 → W3 바코드/OCR 스캔 플로우 → W4 매칭 엔진+Match Score → W5 결과 UI+공유 카드+Shelf → W6 QA·성능(LCP<2.5s)·베타 50명.

## 8. GTM (요약)

1. **Reddit r/AsianBeauty**: "한글 성분표 찍으면 영어로 분석해주는 무료 툴 만들었어" 인디 개발자 포스트 → 랜딩 유입 → 웨이트리스트. (셀프 프로모션 규정 확인, 계정 히스토리 먼저 쌓기)
2. **TikTok 마이크로 인플루언서(5천~5만)**: 무료 사용 + 전용 코드 + 레비뉴 쉐어. 스캔하는 장면 자체가 후킹 비주얼.
3. **동남아 공구 총대**: B2B 리포트+물류 원스톱 제안.

## 9. KPI

- Phase 0: 웨이트리스트 2,000명, Reddit 포스트 upvote 500+
- Phase 1: 주간 스캔 수, 스캔→가입 전환 30%, D7 리텐션 15%, 공유 카드 생성률
- Phase 2: 스캔→구매 전환 3%, AOV $35+, 배치 참여율, 크리에이터 매출 비중

## 10. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 성분 등급 데이터 저작권(EWG) | 공개 DB(CosIng·식약처·CIR) 기반 자체 등급 체계 (§6) |
| OCR 정확도(광택 용기, 작은 글씨) | 바코드 1차 + OCR 폴백 + 검수 큐 + 유저 신고 |
| 국가별 화장품 수입 규제(태국 FDA 등) | 초기엔 개인사용 목적 소량 직구 범위로 한정, 국가별 통관 가이드 내재화 |
| "의학적 효능" 표현 규제 | 분석 문구를 "정보 제공" 톤으로 고정, 법무 검수 카피 라이브러리 |
| 물류 CS(파손·지연) | 초기 국가 2~3개로 한정(싱가포르·미국·필리핀), 풀필먼트 SLA 계약 |
| 화해의 글로벌 진출 | 속도 + 기후 매칭 + 커뮤니티 락인으로 선점. 데이터(스캔 로그)가 해자 |
