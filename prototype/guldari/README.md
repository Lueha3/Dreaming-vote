# 굴다리(Guldari) — 소형 무대 웹 프로토타입

`docs/metaverse-concert/` 기획의 첫 번째 목업. **굴다리 아래 첫 공연**의 코어 루프를 브라우저 하나로 시연한다.

## 실행

```bash
cd prototype/guldari
python3 -m http.server 8123
# http://localhost:8123 접속 (사운드 있음 — '입장하기' 클릭 후 재생)
```

`?fast=1` 쿼리를 붙이면 곡 길이가 4마디로 줄어 전체 루프(공연→별점→앙코르/종료)를 빠르게 확인할 수 있다.

## 시연되는 기획 요소

| 기획 문서 | 프로토타입 구현 |
|---|---|
| 06 §3-1 맵별 사운드 정체성 | Web Audio `ConvolverNode` 합성 IR로 터널 리버브(RT60 ~1.9s) — HUD의 '터널 리버브 ON/OFF' 토글로 공간감 차이를 직접 비교 |
| 02 §4 저음 반응 연출 | `AnalyserNode` 저역 에너지 → 나트륨등 펄스·카메라 미세 셰이크·관중 바운스 진폭 |
| 06 §3-2 다이어제틱 UI | 동전 던지기(포물선 물리 → 기타 케이스 안착 + 클링크 SFX), 폰 플래시 물결(글로우 스프라이트) |
| 06 §3-2 행인 NPC | 흥분도 비례 확률로 걸음을 멈추고, 일정 확률로 관객 전환("행인이 관객이 되었습니다") |
| 01 §2-5 앙코르 게이지 | 박수·플래시·동전으로 충전, 60%+ 달성 시 별점 제출 후 숨겨둔 앙코르 곡 해금 |
| 01 §5 리워드-별점 분리 | 별점 제출 시 "관람 +20 / 평가 +10 SP — 별점 값과 무관" 카피 그대로 |
| 06 §1 미션 카운터 | 종료 화면 "오늘, 한 곡이 처음으로 관객을 만났습니다" + 성장 사다리 CTA |

## 파일

- `index.html` — UI/HUD (입장 → LIVE → 별점 → 앙코르 → 종료 화면)
- `app.js` — Three.js 씬(굴다리·무대·관중·행인·동전 물리) + Web Audio(프로시저럴 로파이 곡·리버브·SFX)
- `three.min.js` — Three.js r147 UMD (로컬 번들, 외부 CDN 무의존)

음악은 저작권 무관하게 Web Audio 오실레이터로 실시간 합성(Fmaj7–Am7–Dm7–G7 로파이 진행)한다. 실제 제품에서는 유저 업로드 곡(HLS)이 이 자리에 들어간다.

## 스튜디오 — 곡 업로드 파이프라인 (2차)

홈에서 **🎤 내 곡으로 데뷔하기**를 누르면 업로드 → 검수 → 셋리스트 → 무대 전 과정을 밟는다.

| 단계 | 실제 동작 | 실제 제품에서 대체될 자리 |
|---|---|---|
| 1. 곡 올리기 | `decodeAudioData`로 mp3/wav/m4a 디코딩. 파일은 브라우저 밖으로 나가지 않음 | Supabase Storage / Cloudflare R2 업로드 + FFmpeg 트랜스코딩 워커 |
| 곡 분석 | 파형 피크, **onset 자기상관 BPM 검출**(1차 차분 하이패스 + 옥타브 오류 보정), RMS 기반 라우드니스 → -14 LUFS 정규화 게인 | 서버측 분석 배치 |
| 연출 자동 생성 | 4마디 창 에너지로 섹션 변화 탐지 → 조명 플레어/암전, 4마디마다 색 전환, 최고 에너지 구간에 떼창 유도. 파형 위에 큐 마커 표시 | 연출 시퀀서의 AI 초벌 생성 |
| 2. 권리 확인 | 본인 창작·제3자 권리 미침해 체크(둘 다 필수), AI 사용 여부 3단계 + 사용 툴 기재 | 약관 편입 + 업로더 권리 보증 기록 |
| 검수 | 트랜스코딩 → 핑거프린트 대조 → 커버곡 인식 → AI 판별 4단계 진행 표시(**시뮬레이션**). AI 신고 시 'AI 생성' 라벨 부착. '다른 결과 보기'로 유사곡 감지 시나리오(반려가 아닌 **검수 대기 + 이의신청**) 확인 가능 | ACRCloud 핑거프린트·커버 인식·AI Music Detector API |
| 3. 셋리스트 | **최대 15곡**(요구사항 1) 하드 제한, 순서 변경·삭제, 예상 공연 시간 계산 | DB `SetlistItem.position <= 15` 제약 |
| 무대 | 업로드한 곡이 **터널 리버브를 통과해 재생**되고, 곡 진행바·곡 순서 표시, 생성된 연출 큐가 시간에 맞춰 발동(조명 플레어·색 전환·떼창), 곡 사이 아티스트 멘트 | HLS 동기 재생 + Colyseus 룸 브로드캐스트 |

파일이 없으면 **데모 곡으로 체험하기**가 프로시저럴 곡을 `OfflineAudioContext`로 렌더해 동일한 흐름을 태운다.
